## 1. 离线范围定义

### 1.1 核心原则

- **本地优先：** 所有用户数据（GPX 文件、轨迹、统计）本地持久化，不依赖网络
- **功能降级：** 网络不可用时，核心引导功能不受影响，地图底图优雅降级
- **无网络冷启动：** 应用可在完全无网络状态下启动，加载已保存的路线

### 1.2 离线能力清单

| 功能 | 离线可用 | 说明 |
|---|---|---|
| 应用启动 | ✅ | 无需网络，本地资源加载 |
| 路线库查看 | ✅ | 本地 SQLite 数据 |
| 路线统计 | ✅ | 本地计算 |
| 二维路线视图 | ✅ | Canvas 渲染，无底图 |
| 海拔剖面 | ✅ | SVG 渲染，本地数据 |
| GPX 导入 | ✅ | 本地文件解析 |
| GPS 定位 | ✅ | 原生 GNSS，不需要网络 |
| 轨迹匹配 | ✅ | 本地算法 |
| 偏航告警 | ✅ | 本地声音/振动 |
| 三维地图 | ❌ | 需要网络加载瓦片 |
| 在线地形 | ❌ | 需要网络加载 |
| 高德地图 | ❌ | 需要网络 + 凭据 |
| 道路导航 | ❌ | 需要网络算路 |
| 航点搜索 | ❌ | 需要网络数据 |

### 1.3 不包含（P1 候选）

- 离线底图/地形包下载
- 持久瓦片缓存
- PWA 离线安装
- 云同步

## 2. 验收场景

### 场景 O-01：离线冷启动

**前置条件：**
- 应用已安装，至少导入过 1 条路线
- 设备完全断网（飞行模式或无信号）

**操作步骤：**
1. 启动应用
2. 查看路线库
3. 打开任意已保存的路线

**预期结果：**
- ✅ 应用正常启动，无加载错误
- ✅ 路线库显示已保存的路线列表
- ✅ 路线详情（名称、距离、爬升、点数）正确显示
- ✅ 二维路线视图正常渲染
- ✅ 海拔剖面正常显示
- ✅ 无网络错误提示或崩溃

**验证方法：**
```
□ 飞行模式下启动应用
□ 路线库加载正常（截图）
□ 路线详情显示完整统计
□ 二维路线渲染正确
□ 无网络相关错误日志
```

### 场景 O-02：离线 GPX 导入

**前置条件：**
- 设备完全断网

- ✅ 统计数据正确计算
- ✅ 路线保存到本地 SQLite
- ✅ 刷新后路线仍在

**验证方法：**
```
□ 导入多轨 GPX 文件
□ 导入多段 GPX 文件
□ 导入含高程的 GPX
□ 导入含时间的 GPX
□ 刷新后路线持久化
```

### 场景 O-03：离线定位引导

**前置条件：**
- 已打开一条路线
- 设备完全断网
- GPS 信号正常（户外或窗边）

**操作步骤：**
1. 点击"开始引导"
2. 等待首次定位
3. 观察匹配状态
4. 模拟偏离路线

**预期结果：**
- ✅ 定位权限请求正常
- ✅ 首次定位在 30 秒内
- ✅ 轨迹匹配正常工作
- ✅ 偏离超过阈值后触发告警
- ✅ 告警包含声音 + 振动
- ✅ 回到路线后告警清除

**验证方法：**
```
□ 飞行模式下启动引导
□ 首次定位时间 < 30 秒
□ 沿路线行进显示"沿路线"
□ 偏离 150m 触发告警
□ 告警包含声音 + 振动
□ 回到 20m 内清除告警
```

- ✅ 恢复定位后自动匹配

**验证方法：**
```
□ 定位丢失 > 10 秒
□ 显示"定位不确定"
□ 不触发误报偏航
□ 恢复后自动匹配

```

## 5. 已知限制

1. **无离线底图：** 二维视图无底图，仅显示路线和网格
2. **无离线地形：** 三维视图需要网络，离线时不可用
3. **无离线算路：** 道路导航需要网络，偏离后不自动回归
4. **GPS 依赖：** 室内或地下可能无法定位
5. **系统限制：** 省电模式可能影响定位频率
