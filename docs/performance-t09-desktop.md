# T-09 桌面解析性能基准

> 生成日期：2026-10-19  
> 范围：桌面环境 GPX 解析性能（`parseGpx`）  
> 工具：`npm run bench:parse`

## 运行环境

- Node.js: `v24.19.0`
- npm: `11.17.0`
- 运行命令：`npm run bench:parse`
- 说明：本结果仅衡量桌面解析耗时，不代表移动端帧率、内存峰值或户外导航体验。

## 基准结果

| 点数 | XML 大小 | 解析耗时 | 内存增长 | 输出点数 | 距离 | 结论 |
|---:|---:|---:|---:|---:|---:|---|
| 10,000 | 0.98 MB | 339.6 ms | 未启用 `--expose-gc` | 10,000 | 202.9 km | 通过 |
| 50,000 | 4.91 MB | 1140.9 ms | 未启用 `--expose-gc` | 50,000 | 1074.3 km | 通过 |
| 200,000 | 19.65 MB | 4261.3 ms | 未启用 `--expose-gc` | 200,000 | 4298.0 km | 通过 |

## 结论

- 桌面端可在当前环境中成功解析 10k / 50k / 200k 点合成 GPX，并保留点数统计。
- 200k 点解析仍在 20 MB 文件上限内通过，但耗时明显上升，接近当前性能压力区。
- 移动端真机性能、内存峰值、帧率和发热仍待补充，不能由桌面结果直接替代。

## 备注

- 若后续需要更严格的峰值内存统计，可在单独环境中使用 `node --expose-gc` 或系统级观测工具。
- 本脚本仅验证解析路径，不覆盖渲染、绘制、滚动或三维地图交互性能。
