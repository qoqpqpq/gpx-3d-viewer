# 轻量后端与上线配置

当前新增 Node.js 后端，无第三方运行时依赖。GPX 解析、统计、导航判断及 IndexedDB 仍在浏览器内完成，没有轨迹上传接口。

## 本地启动

Node.js 22.12+。`npm run dev` 同时启动 Vite（5173）和后端（8787）；Vite 代理 `/api` 与 `/_AMapService` 到后端。现有“启动预览.cmd”也走此启动方式。仅启动后端用 `npm run server`。

编辑项目根目录 `.env.server`（已加入忽略规则），填写：

- `AMAP_WEB_KEY`：高德 Web 端 JS API Key。这个 Key 仍会发给浏览器，是公开应用标识。
- `AMAP_SECURITY_CODE`：配套安全密钥，只由后端读取，不使用 VITE_ 前缀。
- `ADMIN_TOKEN`：用随机长字符串保护用量接口，例如本地执行 `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"` 生成，保存到文件。

填写后重启后端，再应用地图设置。前端探测到服务器已配置后自动使用代理，删除当前标签页旧的 `amap-security`，隐藏浏览器安全密钥输入框。不会自动读取浏览器里的真实密钥写入服务器。

开发环境未配置后端时保留原直连调试；**正式构建禁止退回前端安全密钥方式**。服务器只代理高德，Cesium/TianDiTu 仍是受限前端 token/Key，必须另设平台权限/域名限制。

## 正式运行

1. 设置正式高德域名白名单并确认服务授权。
2. 在 `.env.server` 设置 `ALLOWED_ORIGINS=https://你的域名`（多个精确 origin 用逗号分隔），填写服务器凭据和管理员令牌。
3. 执行 `npm run build`，然后 `npm start`。同一 Node 服务提供 dist 静态文件、API 和代理，默认只监听本机 8787。
4. 用 HTTPS 反向代理接到 8787，并配置进程守护。不要把 .env.server、源代码目录或整个项目根目录公开为静态目录。开发服务器不用于公网。

`npm run preview` 仅预览静态产物，不提供后端代理；验证正式流程应使用 `npm start`。

## 接口与边界

- `GET /api/health`：健康状态。
- `GET /api/map-config`：公开高德 Web Key、代理地址及是否配置，不返回安全密钥。
- `GET /api/usage`：必须携带 `Authorization: Bearer <ADMIN_TOKEN>`，返回进程启动时间、代理请求、上游请求、响应字节、拒绝数、失败数和当天用量。不要把管理员令牌放入 URL 或网页。
- `GET /_AMapService/v3/vectormap`：固定代理 fmap01.amap.com。
- `GET /_AMapService/v4/map/styles`：固定代理 webapi.amap.com。

代理遵循高德官方 serviceHost 方式；不开放搜索、导航等未使用接口，未知路径拒绝。服务端覆盖客户端传入的 key/jscode，不转发 cookies/authorization，不跟随上游重定向；12 秒超时、8 MB 响应上限。错误只返回固定代码，不记录含密钥的 URL。

默认每个实际 TCP 来源 IP 每分钟 180 次，每个服务进程 UTC 日累计 20,000 次。超过上限返回 429；可通过 PROXY_PER_MINUTE/PROXY_DAILY_LIMIT 调整。代理校验 Origin/Referer 与 Fetch Metadata；这些不能替代登录鉴权，也不能完全阻止脚本盗刷。

**限流和统计使用内存，重启清零，多实例不共享**。置于 Vite/Nginx 后方时默认按代理服务器 IP 合并计数，故意不信任任意 X-Forwarded-For；正式部署应由可信网关按用户/IP 限流，按容量调整此应用级阈值。更大规模需要 Redis/数据库持久化、认证、计费告警与网关策略。

统计仅涵盖上述代理请求，不含 SDK 直连请求及 Cesium/天地图使用量，不代表高德初始化计费次数或账号完整账单。真实账单仍以供应商控制台为准。当前没有自动告警，也没有绕过供应商额度限制。

## 验证

`npm test`：30 项前端/算法/地图适配回归。
`npm run test:server`：6 项后端集成测试，覆盖敏感配置隔离、用量鉴权、固定上游、凭据覆盖、跨站请求拒绝、限流/UTC 日重置、错误脱敏、未配置响应以及静态目录隔离。
`npm run build`：TypeScript 与生产打包。

真实高德代理链路需填写服务器凭据后联调；当前测试用伪造上游响应，没有把真实密钥写进测试或日志。
