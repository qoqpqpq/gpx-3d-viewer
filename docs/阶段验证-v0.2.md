# v0.2 底图与可用性检查

检查日期：2026-09-28。范围：本机浏览器桌面预览；合成演示 GPX、两分段测试 GPX；代码审查及自动化回归。不代表 Android 或户外验收。

## 按使用步骤检查

1. 打开路线、查看地形：原先仅加载地形，无影像且未开启地形光照，缺乏周边参照。已加入 Cesium 全球影像、天地图卫星影像/道路地图、中文注记开关。2D 和 3D 均支持底图；地形和底图独立加载；保留无网络的本地路线视图和连接重试。实机浏览器已显示 Cesium 影像与地形。天地图接口和参数已实现，用户填写 Key 后仍需验证实际瓦片权限、网络和中文注记。证据：[修改前](audit-v0.2/01-before-map.png)、[修改后](audit-v0.2/02-after-map.png)。健康：桌面行前查看可用，天地图待凭据联调。
2. 导入与选点：修复同一文件删除部分路线后无法重新导入缺失路线；保留已有路线及其重命名。修复地形异步加载后选点/定位标记丢失；地图可点选路线；隐藏会随旋转产生误导的固定指北标记。健康：核心读取流程可用；部分重新导入变更经过代码审查，尚未做完整浏览器端删除/重导入回归。
3. 模拟行进：增加明确的分段选择；正反向回放到断口停止，不自动跨越；相同累计里程的不同分段端点可准确选择。修复反向首次零时间步立即结束、NaN 定位时间污染判定、跨分段跳点误判及退出浏览器定位后的控件复位。健康：算法回归通过，真实定位尚未验收。
4. 配置地图：入口为“底图与地形”；已有 Cesium token 留空保留；天地图 Key 独立填写；凭据保存在当前标签页会话，不显示已保存的值、不写入源代码。输入错误会在弹窗内提示。健康：可配置，天地图在线成功与否取决于用户 Key 和网络。

## 户外首版仍缺的关键能力（优先级）

- P0：Android 原生定位/前台服务、锁屏持续定位、被系统回收后的状态恢复、权限关闭处理。
- P0：偏航声音/振动在锁屏下的端到端验证；真实道路/山径采样、交叉口、平行路、漂移、弱信号和分段重新锚定测试。
- P0：可用的离线底图/地形方案及下载、空间预算、完成校验、失效处理。当前只保证已导入 GPX 存在本地；不是离线地图包，页面冷启动也未实现 PWA 缓存。
- P1：导航会话保存、当前轨迹记录与导出、定位丢失显著提醒、地图跟随/朝向、路线搜索排序和更适合户外操作的大按钮。
- P1：地图服务请求超时/瓦片缺失的更精细恢复、离线重连压力测试、200k 点轨迹在目标手机上的内存/帧率及电量测试。

建议继续采用“桌面完成查看与算法 → Android 最小定位链路 → 离线能力 → 户外验收”的顺序。不要把新增影像视为已完成户外导航。

## 验证

- 26 项 Vitest 测试通过：保留原 GPX 数据和导航测试，新增分段边界、正反向断口停止、无效时间、跨段重定位、凭据迁移/校验、天地图图层配对及 Key 编码。
- TypeScript 检查与 Vite 生产构建通过。
- 浏览器实见 Cesium 在线地形和卫星底图叠加；天地图实际服务尚未验证。
- 测试没有读取或记录用户 token/Key，没有申请浏览器实际定位权限。
