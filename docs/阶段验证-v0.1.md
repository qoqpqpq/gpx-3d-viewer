# v0.1 电脑预览阶段验证

日期：2026-09-28。对应规划：v1.1，以及用户追加的“电脑浏览器可交互原型先行”。

## 本阶段交付

已建立可构建、可本机运行的浏览器工作台。包含本地 GPX 导入/持久化、二维路线、Cesium 三维高程线、海拔剖面、模拟定位与偏离提醒。主入口为 `http://127.0.0.1:5173`。此阶段没有交付 APK，也不代表原规划 S0/S1/S2 已整体通过。

## 环境与版本

Windows；Node.js 24.18.0；TypeScript 7.0.2；Vite 8.3.1；Cesium 1.145.0；fast-xml-parser 5.11.1；GeographicLib Geodesic 2.2.0；Vitest 5.0.2。依赖已固定版本并生成 package-lock.json。

## 自动检查

`npm run build` 通过：包含严格 TypeScript 检查及生产构建。Cesium Workers、Assets、Widgets、ThirdParty 使用本地资源；已检查产物路径为 `dist/cesium/` 对应目录。

`npm test`：19 项通过，覆盖：

- WGS84 赤道参考距离；多段不计跨段距离。
- 多轨、前缀命名空间、航点、路线控制点、标准 XML 实体。
- 缺高程/时间、负高程、无效坐标断段、逆序时间及跨段历时口径。
- 截断 XML、空文件、DTD、过深层级拒绝。
- 日期变更线的距离与里程插值。
- 剖面显示采样不改统计；平海拔发卡形折线简化保留转折。
- 50,000 点解析不静默丢点（仅电脑环境，不是 Android 性能结论）。
- 到线段中点距离；连续偏离 5 秒、恢复滞回、重复提醒抑制。
- 过期/低精度定位不告警；失联间隔不累计为连续偏离。
- 持续平行偏离后前进并重新回到路线。
- 环线起终点匹配及远距离跳点要求重新确认锚点。

## 浏览器实测

在 Codex 内置浏览器通过实际界面操作验证：

| 项目 | 结果 |
|---|---|
| 演示路线启动 | 正常，明确标记合成路线 |
| 二维路线与剖面 | 能渲染路线、剖面、航点；模拟过程中位置、里程和高程联动 |
| 桌面/窄屏布局 | 查看了桌面及约 400px 窄屏断点；窄屏为纵向布局 |
| Cesium 三维 | 无 token 的椭球底面/GPX 高程线可见；没有冒充真实地形 |
| 三维失败回退 | 开发中资源路径错误触发二维回退；修复静态资源路径后成功渲染 |
| GPX 实际导入 | 导入 tests/fixtures/two-segments.gpx，显示 5 点、2 段、0.78 km、爬升 90m、段内历时 7m |
| 刷新恢复 | 上述导入轨迹在重新加载后仍存在 |
| 重命名 | 测试路线名称更新并写入本地库 |
| 正常模拟 | 显示距线 0m、精度 ±6m，进度持续更新 |
| 偏离模拟 | 先确认，随后显示已偏离；持续前进不会再把距离误算到旧路段 |
| 回到路线 | 恢复为沿线行进状态 |
| 低精度情境 | 设置为 ±80m，暂停偏离判断 |

浏览器自动化在桌面视口下存在点击坐标定位异常，使用控件键盘操作继续验证；未将其当作应用鼠标事件缺陷。具体设备上的鼠标/触屏手感仍需用户体验反馈。

## 仍未验证 / 未实现

- 未提供 Cesium token，因此未验证真实在线地形、影像、配额与中国大陆网络稳定性。
- 未检测到 Flutter 命令；未创建 Flutter/Android 工程、构建 APK 或测试真机。
- 没有 Android 前台服务、锁屏播报、高德道路导航集成、耗电和长时间稳定性数据。
- 浏览器定位代码已接入，但未请求用户设备定位权限或用真实位置测试；全部路线模拟使用合成数据。
- 声音提醒代码已实现；没有把合成提示音播放当作真机声音/振动验收。
- 本地存储不足、浏览器清数据、最大 20 MB/20 万点、全部异常恢复路径尚未完成压力验收。
- 删除、重复导入和原始 Blob 导出功能已实现，但本次未逐项完成端到端浏览器复测。
- 未实现持久地形缓存、离线地图包或 PWA；本地服务运行时二维功能不依赖外网。
