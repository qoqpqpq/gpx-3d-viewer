# 山径 · Ridgeline

GPX 路线工作台。当前交付是 **v0.1 电脑浏览器原型**，用于验证行前查看和轨迹引导逻辑；尚不是可依赖的 Android 户外导航版本。

## 在电脑上运行

环境：Node.js 22.12+（本次使用 24.18.0）。在项目目录执行：

```powershell
npm ci --registry=https://registry.npmjs.org
npm run dev
```

已有 `node_modules` 时可直接双击 `启动预览.cmd`，或执行 `npm run dev`。打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。服务只监听本机，不对局域网或公网开放。

```powershell
npm test          # 核心逻辑测试
npm run build    # 类型检查 + 生产构建
npm run preview  # 生产构建预览，http://127.0.0.1:4173
```

不要双击 `dist/index.html`；Cesium Worker 与模块资源需要 HTTP 服务。浏览器存储按 origin 隔离，5173 与 4173、localhost 与 127.0.0.1 不共享轨迹库。

## 现在可以做什么

- 打开即有合成演示路线，不需要账号或密钥。演示数据不用于实地行进。
- 导入/拖入 GPX，本地轨迹库、重复文件提示、多轨分开保存、重命名、删除副本、导出原始文件。
- 二维无底图路线：拖动、缩放、全线适配、点击选点；与海拔剖面/里程滑块联动。
- Cesium 三维：本地打包资源，按需加载；未配置 token 时为椭球底面和高程线，不是假装真实地形。
- 正反向模拟、播放速度、正常/偏离 150 米/定位精度不足三种情境、声音提醒。
- 可选浏览器前台定位，需要用户主动授权；后台自动暂停，返回后手动重启。

## 连接真实地形

点击“地形设置”，填入自己的 Cesium ion **只读 token**，点击“应用并打开三维”。请按所用资产授权配置最小 `assets:read` 权限；不要填管理/写权限 token。

- 影像 Asset ID 可选，留空只加载地形。
- token 保存在当前标签页的 sessionStorage，不保存到源文件或轨迹库；清空输入并应用即可移除。
- 网络或鉴权失败会显示状态，二维路线仍可用。
- GPX 在本地处理；开启在线地形/影像后，请求区域和凭据会发送到 Cesium/相应地图服务商。
- 本次没有收到 token，因此没有验证真实在线地形、影像或大陆网络覆盖。

## 数据及算法口径

- GPX 1.0/1.1、命名空间、多轨、多段、rte、基础 wpt；每条轨道独立保存。只支持 UTF-8 文本 GPX。
- 当前输入限制：20 MB、整文件 200,000 点、128 条轨道、单条轨迹 1,000 段、XML 深度 64。超限拒绝，支持取消解析；不启用 DTD/外部实体。
- 解析与统计在 Web Worker 内进行。一个文件的多轨保存使用同一 IndexedDB 事务；保存阶段短暂禁用取消，避免半批写入。
- 原始文件 Blob 保留用于导出。分析使用完整有效点；无效坐标处断段，不计段间距离。
- 距离：GeographicLib 的 WGS84 椭球测地距离。实际历时为段内时间差之和，缺失/逆序时不提供。
- 高程：保留 GPX 原值，未知垂直基准。累计升降采用 **3 米滞回锚点**（当前算法 v0.1）；缺任一点高程时不报完整累计升降。不是经过 DEM 校正的真实爬升。
- 地图使用米制 Douglas–Peucker 显示简化；剖面按桶保留极值。两者不改变统计与匹配数据。
- 偏离实验参数：精度超过 35 m 或位置超过 10 s 则不判断；超出 `max(40 m, 2 × 精度)` 连续 5 s 触发；回到 20 m 内连续 3 s 清除。采样间隔大于 5 s 重新确认。
- 匹配以线段为单位，用前次沿线里程 ±400 m 限制跨分支跳转；距线 200 m 内维持投影进度。遇到远距离跳点需要重新选择锚点，不能当作正常前進。参数未经过户外校准。
- 多段的模拟可能切到下一段，断口不会被绘制为道路；它不证明段间有路。实地版本需要明确的分段接续流程。
- 页面展示的是沿线投影进度，不是实际累计行走里程；模拟器结束不表示实地到达。

## 工程结构

```text
src/core/            数据模型、GPX 解析、地理计算、轨迹匹配
src/adapters/        IndexedDB 存储、浏览器定位适配器
src/ui/              Canvas 二维与 Cesium 三维渲染
src/parse.worker.ts  导入工作线程，可终止取消
src/main.ts          工作台界面、模拟器、交互协调
tests/               算法回归测试、合成 GPX 样例
docs/                规划、阶段验证记录
```

定位适配器输出带 `crs: WGS84`、来源、时间戳和精度的 `LocationFix`。未来 Android 用原生前台服务提供位置与提醒，不能把浏览器定时器作为后台引导方案。TypeScript 核心与未来 Dart/Kotlin 核心通过共同测试向量对齐，当前未承诺原生代码直接复用。

## 当前边界

- 没有 Flutter/Android 工程、APK、原生前台定位、高德集成或真机验收。
- 没有离线底图/地形下载、PWA 离线安装或账号云同步。本地服务运行时，二维功能不需要外网；浏览器清站点数据会删除本地副本，请保留原文件。
- Cesium 资源随应用打包，不依赖公共 CDN；三维失败会回退二维。
- 本次测试覆盖见 [阶段验证记录](docs/阶段验证-v0.1.md)。下一阶段应先完成目标 Android 机型的锁屏定位/提醒原型，再扩展户外功能。

## v0.2 地图设置

在“底图与地形”选择“天地图 · 卫星影像”或“天地图 · 道路地图”，填入天地图浏览器端 Key，点击“应用地图设置”。已有 Cesium token 留空即可保留；Cesium 提供三维地形，天地图提供底图和中文注记。2D/3D 均支持底图。凭据仅保存当前标签页会话。

也可直接选 Cesium 全球影像使用现有 token（需资产权限）；没有网络时点击地图右侧“2D”退回本地路线。离线 GPX 不等于离线底图，也不等于应用可离线冷启动。详见 [v0.2 检查记录](docs/阶段验证-v0.2.md)。

## 城市建筑图层

“底图与地形”中新增“显示建筑（仅三维）”，首次默认启用。使用现有 Cesium token 加载 Cesium OSM Buildings；天地图仍提供影像和注记。二维模式不请求建筑，关闭开关会释放原三维场景内的建筑资源。连接超时或权限不足只影响建筑层，状态栏提供提示，可以点击重试地图连接。OSM 覆盖不完整，没有楼块不一定是加载失败；普通楼块不是带真实外墙的实景模型。

验证：TypeScript/Vite 构建及 26 项既有测试通过；本机浏览器显示 OSM 建筑已启用，关闭/重新开启可正常工作。目标城市具体楼块覆盖尚未逐区域验证。

## 高德城市地图（可选）

在“底图与地形”中选择“高德 · 城市地图与三维楼块”，填写高德 Web 端（JS API）Key 和配套 securityJsCode，应用后切换“三维预览”，放大到街区查看楼块。可用原有建筑/地名开关；原 Cesium、天地图凭据留空保留，切换回来仍可使用。JS API 2.0 的实际样式、楼块覆盖以开放平台提供的内容为准，不保证与高德手机 App 截图一致。

高德采用独立地图渲染，不与 Cesium 地形叠加。SDK 被放在可销毁的本地 iframe 内，切换模式或修改 Key 会重建 SDK。加载失败/25 秒超时退回本地路线，提供重试入口。凭据仅保存在当前标签页会话；这是本机预览接入，公开部署应使用高德官方推荐的服务端安全代理。

路线、选点和前台定位仅在显示边界近似转换为 GCJ-02；点选反算回 WGS84。GPX 原件、距离、海拔及偏航算法保持 WGS84，不调用在线坐标批量转换服务。大陆边界附近及实际路线与楼块的对齐仍需实测，不能将该显示转换当成测绘精度保证。

验证：29 项测试通过（含坐标参考值、往返转换、源数据不变与高德凭据对校验）；TypeScript/Vite 构建通过；浏览器配置入口已检查。高德地图实际加载、楼块覆盖与凭据权限待用户在页面填写后联调。

官方参考：[展示地图](https://lbs.amap.com/api/javascript-api-v2/tutorails/display-a-map)、[三维地图](https://lbs.amap.com/api/javascript-api-v2/guide/map/3d-map)。

### 高德地形（测试版）

新增独立选项“高德 · 地形（测试版）”，复用高德 Key/securityJsCode。应用此选项自动切换三维；内部使用官方 JS API 2.1Beta 和 terrain:true。切换二维时关闭地形，重新切回三维恢复；城市选项仍用 2.0。不同模式通过重建 iframe 隔离 SDK 版本。地图就绪状态不代表每块地形/建筑均已加载，GPX 贴地、楼块共存与山区覆盖仍需目标区域实测。构建及 29 项既有回归测试通过。

## 轻量后端（新增）

`npm run dev` 现在同时启动前端和 Node 后端。高德安全密钥放在 `.env.server`，配置后自动使用服务器代理；正式构建要求使用代理。包含固定接口白名单、限流、每日预算和令牌保护的用量查询。详见 [后端配置与部署](docs/后端与部署.md)。此前文档中的浏览器安全密钥输入仅适用于本地直连调试。
